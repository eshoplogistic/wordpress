Проверка нескольких городов отправителя (в установленном WordPress):
wp --path=/path/to/wordpress eval-file wp-content/plugins/eshoplogisticru/tests/sender-cities.php

Использует данные и сессию в памяти, подменяет ответы API и кэша.
Не обращается к внешнему API и не меняет сохранённые настройки или заказы.
